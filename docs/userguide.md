# User Guide

1. Start the app with `python task_manager.py`.
2. **Add:** press 1, type a title. Blank titles show an error.
3. **Show:** press 2 to list tasks. `[x]` means completed.
4. **Complete:** press 3, enter the task ID.
5. **Delete:** press 4, enter the task ID.
6. **Quit:** press 5. Tasks are saved automatically in `tasks.json`.

Errors (unknown ID, non-numeric ID, empty title) are shown as
"Error: ..." and the app keeps running.
